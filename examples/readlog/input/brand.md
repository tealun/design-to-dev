# Readlog 品牌规范 v0.3（节选）

## 颜色
| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Ink 墨 | #1F2A2E | 正文、标题 |
| Paper 纸 | #FBF7F0 | 页面背景 |
| Moss 苔绿 | #3E7C59 | 主按钮、进度、链接（品牌主色） |
| Amber 琥珀 | #E3A23B | 连续打卡、成就 |

## 字体
- 标题：思源宋体 Noto Serif SC，粗体。
- 正文：系统默认无衬线。

## 其他
- 圆角柔和，不要尖角。
- 主按钮在手机上通栏。
- 语气：温和、鼓励，不说教。比如“今天也读了一点，很好”。
