## 背景

用户认为 1.1 的示例和模板“太丑、没有美感、审美不够档次”。1.2.0 先补上审美标准、视觉方向和视觉自查，再做两件事验证：用新模板重做 Readlog，并用一份设计水准高的公开登录页实测。

## 新稿件实测：公开登录页

- 稿件：Vercel 登录页 `https://vercel.com/login`，1440 宽、2 倍截图；Linear 登录页也能取得，选了元素更多的这一份。他人产品：品牌名和标志替换为 “Acme”，第三方截图和产物不入库。
- 按 1.2.0 SKILL.md 执行：palette.py 取色 → tokens（参考稿取色记为【示意】）→ 原型 → 标注 → HANDOFF → check_output → 浏览器走查 → 视觉自查。
- 流程走查：空邮箱、格式错误、输入即清除报错、未知邮箱提示、同一地址第二次失败（1.1.1 的 F-01 修复在真实页面里生效）、演示账号到达结束页、超范围链接提示，均无控制台报错。

## 发现与改动

| # | 现象（证据） | 1.2.0 的改动 |
| --- | --- | --- |
| G1 | 并排目测觉得“差不多”，测量后发现标题高了 43px、按钮间距 8px 而参考是 16px、缺一条分隔线、按钮文字 14px 而参考约 16px。 | `palette.py --rows x0-x1` 输出某一列中各区块的位置和高度（按 1 倍换算）；视觉自查第 11 项要求两张截图用它测量，关键区块误差不超过 4px。修正后各区块误差为 0–3px。 |
| G2 | 参考稿自身不达标：链接 `#0072f5` 在 `#fafafa` 上只有 4.26:1，页脚灰 `#8f8f8f` 只有 3.10:1；技能没有说明这种情况怎么处理。 | 视觉方向参考新增“对比度”一行：用最接近的达标色，原值写进 token 注释，并列入待定问题。 |
| G3 | 检查脚本把规格说明里提到的参考色值（`#8f8f8f`）当成原始色值报错；同类误报 `#add`、`#bad`（审计 F-06）。 | `check_output.py` 不再检查注释、`data-spec-note`、`href="#…"` 与选择器里的 `#…`；内联样式里的颜色仍会报错。补两条回归测试。 |
| G4 | 截图脚本按 `=` 拆分参数，导致 `?state=empty` 被截断，四张状态截图其实是同一张，目测时差点误判为“状态没生效”。 | 属于会话里的临时脚本，不在技能内；已修正，并在自查中核对截图哈希值是否互不相同。 |
| G5 | 1.1 的模板按钮、输入框、列表都是“能用”的默认样式，没有审美约束。 | 新增视觉方向参考；模板按现代精致极简重做；第 1 步必问 VI 与视觉参考。 |
